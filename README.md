# ActivLog
ActivLog is a native Android application built with Kotlin in Android Studio used for tracking fitness activities.

[Demo video](https://youtu.be/6omfpl6rkt4)

## Features
- Create/read/update/delete activities.
- Add activity type, time, RPE (Rate of Perceived Exertion), optional start and end locations, and optional note.
- Light/dark themes.
- Map displaying tracked activity locations.
- Statistics page.

## Installation instructions
1. Clone the repository.
2. Open the project in Android Studio.
3. Build and run the application on an Android device or emulator.
